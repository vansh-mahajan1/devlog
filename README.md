# 📚 Command Line Study Logger

A simple **Command Line Study Logger** built with Python to keep track of what I study and how much time I spend studying.

The program stores each study session in a text file and calculates the total study time.

## 🚀 Features

- 📝 Log what I studied
- ⏱️ Record study time in minutes
- 📅 Automatically record the current date
- 💾 Save study sessions to `log.txt`
- 📖 View previous study sessions
- 🧮 Calculate total study time
- 💻 Runs directly from the command line
- 🐍 Uses only Python's built-in modules

## How to run it

​```bash
git clone https://github.com/vansh-mahajan1/devlog.git
cd devlog
python3 devlog.py
​```
